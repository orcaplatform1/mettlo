METTLO — SUNRISE VITALITY
PREMIUM UI / UX DESIGN SYSTEM + CLAUDE CODE IMPLEMENTATION SPEC
===============================================================

DOCUMENT PURPOSE
----------------
Bu doküman, METTLO'nun "SUNRISE VITALITY" renk paletine göre web + tablet +
mobil arayüzünün Claude Code tarafından eksiksiz uygulanması için hazırlanmıştır.

AMAÇ:
- Premium
- Dinamik
- Enerjik
- Modern
- Fitness + Wellness odaklı
- Kullanıcıyı yormayan
- Uzun süre kullanımda göz konforunu koruyan
- Güçlü fakat agresif olmayan
- Görsel olarak ayırt edilebilir
- Apple/Google seviyesinde temiz ürün hissi
- Mettlo'nun fitness, wellness, coaching, community ve commerce ekosistemini
  tek bir tasarım dili altında birleştirmek

ÖNEMLİ:
Bu sistem yalnızca mobil uygulama için değildir.

METTLO aynı ürün deneyimini:
1. Desktop Web / PC / Mac
2. Tablet
3. Mobile Web
4. iOS
5. Android

üzerinde sunmalıdır.

Aynı kullanıcı hesabı, veri, abonelik, içerik, workout, progress,
community, commerce ve coaching verileri bütün cihazlarda senkronize
çalışmalıdır.


====================================================================
1. MARKA TASARIM FELSEFESİ
====================================================================

METTLO'nun görsel karakteri:

PREMIUM + WARM + ENERGETIC + HUMAN + DIGITAL + WELLNESS

Tasarım:
- Soğuk kurumsal SaaS gibi görünmemeli.
- Ucuz fitness uygulaması gibi görünmemeli.
- Aşırı neon kullanılmamalı.
- Her bölümde gradient kullanılmamalı.

- Primary renk bütün ekranı kaplamamalı.
- CTA, progress, selected state, achievement ve commerce vurgularında
  canlı renkler kullanılmalı.

Ana his:

"Sabah güneşi + hareket + enerji + gelişim + iyi yaşam."
